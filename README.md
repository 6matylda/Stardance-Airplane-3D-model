# Stardance
Hey! This is my first Hack Club project: a bi-engine airplane 3D model.
The model can be optimized to become an RC, so feel free to use and modify it for your own projects! I'd really love to see it fly.

Specifications:
This model features wings with a NACA 4412 airfoil and a NACA 0012 vertical and horizontal stabilizers.
The whole model is hollowed out with a thickness of 0.6mm.
Length: ~729.5mm
Wingspan:  ~7910.67mm
Fuselage diameter: 70mm
· The turbines on the model are placeholders: I recommend to switch them with your own custom ones.

Also; the model does not have ribs and spars yet (internal supports), so I heavily recommend if you are going to print it to add some so it isn't too fragile. :)
